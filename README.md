# Mobile Controller

Transforme un téléphone Android en surface de contrôle tactile (tirettes d'orgue, switches, volume)
et envoie du MIDI à un DAW ou un VST par simple câble USB, sans rien installer sur le PC.

🚧 En cours de développement (MVP v1.0).

## Test

```bash
aseqdump -l                  # repère le port du téléphone
aseqdump -p 24:0             # remplace par TON port
```
